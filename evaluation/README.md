# Learning Evidence

This lane tests bounded learning claims against the dedicated AXM Neural Core. A green run must execute the real core; absence of the core is a failure, never a skipped success. Behavioral claims require measured before/after behavior, replay-vs-control evidence, restart retention, future-trajectory equivalence, and explicit interference retest deltas. Passing these probes does not imply general intelligence, semantic understanding, broad transfer, or long-horizon continual-learning quality.
