# AXM Neural Brain

**Status: PRODUCTION / HEAVY EXPERIMENTAL**

AXM Neural Brain is an active AXM build-and-test target for creating an AXM-owned neural brain from zero and proving direct learning through lived experience.

> **Production / Heavy Experimental** means this repository is in active real AXM development and may be used in live experiments, while its neural architecture, learning rules, persistence model, and interfaces are still allowed to change aggressively. It does **not** mean stable, release-ready, or safety-certified.

## Current direction

- Build the neural brain itself first, without assuming a specific software body.
- Prove that direct experience changes learned state and later behavior.
- Preserve learned state across restart.
- Support explicit checkpoints and rollback so growth can be compared rather than guessed.
- Keep brain-internal wake/sleep or consolidation separate from whether the host software is running.
- Later connect the brain beneath AXM software through explicit experience/action bridges.
- Let each software body expose its own meaningful experience paths rather than pretending every application has the same nervous system.

## Evidence boundary

No claim of successful learning is earned by architecture, changing files, changing weights, or a training loop merely running.

A learning claim requires observable evidence that experience caused a retained change that alters later behavior under controlled comparison.

## AXM roots

Truth before story. Agency / non-domination. Continuity. Wisdom before speed.

Learned state may advise, adapt, generalize, and grow, but must not silently replace canonical software truth, provenance, verification, permissions, or rollback boundaries.
